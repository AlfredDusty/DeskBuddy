# Contributing

Thanks for your interest in Desk Buddy!

1. Open an issue to describe a bug or feature idea.
2. Fork the repository and create a focused branch.
3. Keep Android app and ESP32 firmware changes separated where practical.
4. Test Bluetooth connection, notifications, weather updates, and theme/navigation changes on real hardware when possible.
5. Include clear steps to reproduce bugs and screenshots for UI changes.

Do not commit keystores, passwords, API secrets, personal notification data, or private signing material.
