# Desk Buddy — APK Download and Installation Instructions

This guide explains how to install Desk Buddy from an APK downloaded outside the Google Play Store and how to enable notification access if the version of Desk Buddy you installed requires it.

> **Security note:** Only install Desk Buddy from the official Desk Buddy project/release page or another source you trust. Android and Google Play Protect warnings are security protections. Read each warning carefully. Do not install an APK if Android identifies it as harmful or blocks it for a security reason.

## 1. Download the APK

1. Open the official Desk Buddy download/release page supplied by the developer.
2. Download the Desk Buddy `.apk` file.
3. Wait for the download to finish before opening it.

An APK downloaded outside Google Play may trigger an Android warning because the app is from an unknown source or has not been checked by Play Protect before. This warning does **not automatically mean the app is malicious**, but it also does not prove the app is safe.

## 2. If Android says you cannot install apps from this source

Android normally requires you to approve APK installation for the specific app you used to download or open the APK, such as Chrome or your file manager.

1. When prompted, tap **Settings**.
2. Enable **Allow from this source** for that browser or file manager.
3. Return to the APK and tap **Install**.
4. Once installation is complete, you can turn **Allow from this source** off again if you do not expect to install other APKs from that app.

The exact labels and menu locations vary by Android version and phone manufacturer.

## 3. Google Play Protect warnings

Google Play Protect may offer to scan an unfamiliar APK, display a warning, or block installation if it detects a security risk.

- **Prefer scanning the APK.** If Android offers to scan the app, use that option and review the result.
- If Play Protect says the app is harmful or blocks it, **bypass the warning**. 
- Turn off Play Protect just to avoid a warning. Then you can turn it back on.

For reference, Google’s instructions for Play Protect are available here:
https://support.google.com/googleplay/answer/2812853

## 4. Enable “Allow restricted settings” (only if Desk Buddy requires it)

On Android 13 and later, Android may restrict certain sensitive settings for apps installed from outside an app store. If Desk Buddy legitimately requires notification-listener access and Android blocks you from enabling it, you may need to allow restricted settings for Desk Buddy.

Only do this if you trust the APK and understand why the app needs the permission.

1. Open your phone’s **Settings**.
2. Go to **Apps** or **App management**.
3. Select **Desk Buddy**.
4. Tap the **three-dot menu** in the upper-right corner, if it is available.
5. Choose **Allow restricted settings** and confirm.
6. Return to Desk Buddy’s relevant settings page or Android’s **Notification access** settings.
7. If notification-listener access is required, select Desk Buddy and enable it after reviewing the permission prompt.

Menu names and locations vary by device. If the **Allow restricted settings** option is not shown, your Android version or device may handle this differently.

**Important:** Ordinary app notifications usually only need the app’s notification permission; they do not normally require notification-listener access or “Allow restricted settings.” Grant notification-listener access only if Desk Buddy has a feature that genuinely needs to read or manage notifications from other apps.

## 5. After installation

- Open Desk Buddy and follow its in-app setup instructions.
- Grant only the permissions needed for the features you use.
- If a feature does not work, check Desk Buddy’s app permissions and the relevant Android settings.
- Keep Android, Google Play Protect, and Desk Buddy updated.
