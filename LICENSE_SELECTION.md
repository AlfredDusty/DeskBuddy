# Choosing a license for Desk Buddy

## Recommendation: MIT License

For your stated goal—letting people study, modify, share, and reuse the app and firmware—the **MIT License** is a simple permissive option. It generally allows personal, academic, and commercial reuse, including modified versions, provided copyright and license notices are retained. It provides no warranty.

Choose **GPL-3.0** instead if you want distributed derivative versions of the covered code to remain under the GPL and provide corresponding source under its terms.

Before adding a license, confirm that you own or have permission to license all project code and artwork you wrote or generated, and do not relicense third-party libraries: their own licenses still apply. The repository currently has no `LICENSE` file because the maintainer has not yet confirmed the choice.
